# DOC-STANDARDS — how ACUTE-CODE docs are written + maintained

**Status:** normative · **Established:** round-28 (WS-J1) · **Audience:**
every agent that writes or edits docs in this repo

Owner R28 directive: *"Make sure that the documentation is proper and
easily manageable."* This file + the `scripts/docs/check-stale.mjs` CI gate
enforce that.

---

## 1. Canonical doc structure

Every doc file in `docs/` + repo-root `*.md` MUST have, in order:

1. A `<!-- last-reviewed: 2026-09-11 round-88 -->` HTML comment on the FIRST
   line. `check-stale.mjs` fails CI if this is missing or >3 rounds old.
2. A `# Title` H1 (kebab-case file name → Title Case).
3. A `**Status:**` line (normative | reference | historical | PROPOSED).
4. A `**Established:** round-NN` line (when the doc was created).
5. A `**Audience:**` line (who reads it).
6. A one-paragraph summary.
7. The body (`##` sections).
8. Cross-refs to related docs (relative links, kebab-case).

## 2. File + naming conventions

- **Kebab-case** filenames: `agent-memory.md`, `sandbox-restore.md`. No
  spaces, no uppercase except ADR numbers (`0001-single-agent-mode.md`).
- **No emoji** in doc bodies unless the owner requests them.
- **Markdown only** — no MDX, no HTML except the `<!-- last-reviewed -->`
  comment + inline `<code>`/`<kbd>` tags.
- **Line length**: soft 100 chars; hard 120. Long lines are fine in tables
  + code fences.
- **Code blocks**: always fenced with the language (` ```bash`, ` ```ts`).
  Never use indented code blocks.

## 3. Cross-references

- Use relative links: `[WORKFLOW](../runbooks/WORKFLOW.md)`.
- Never link to absolute paths (`/home/z/...`) in user-facing docs — those
  are sandbox-internal. `check-stale.mjs` flags internal paths.
- ADR cross-refs: `[ADR-0001](../decisions/0001-single-agent-mode.md)`.

## 4. Freshness contract

- Every doc has a `<!-- last-reviewed -->` stamp (rule §1).
- `check-stale.mjs` walks all `docs/**/*.md` + `*.md` at root. For each:
  - parse the stamp; fail if missing or >3 rounds old.
  - extract file-path references (regex `src/...`, `agent-core/src/...`);
    fail if the path doesn't exist (drift guard).
  - extract URL references; HTTP HEAD each; allow 3 failures before failing
    CI (transient outages).
  - extract version references (`v0.1.0`, `Round N`); warn (not fail) on
    mismatch with `package.json` + `status.json`.
- Run: `pnpm docs:check` (added to CI before `pnpm verify`).

## 5. ADR template

ADRs live at `docs/decisions/NNNN-kebab-title.md`. Number sequentially,
NEVER renumber. Use `docs/decisions/TEMPLATE.md`:

- `# NNNN. Title`
- `**Status:** PROPOSED | ACCEPTED | SUPERSEDED by ADR-NNNN | DEPRECATED`
- `**Date:** YYYY-MM-DD`
- `## Context` (why this decision is being made)
- `## Options` (the alternatives considered, with pros/cons)
- `## Decision` (what we chose + why)
- `## Consequences` (positive + negative + neutral)

## 6. Runbook template

Runbooks live at `docs/runbooks/KEBAB-TITLE.md`:

- `# TITLE — one-line purpose`
- `**Status:** normative`
- `## When` (when to follow this runbook)
- `## Steps` (numbered, copy-pasteable commands)
- `## Troubleshooting` (common failures + fixes)
- `## See also` (cross-refs)

## 7. Round-file template

`docs/ui-iterations/round-NN.md`:

- `<!-- last-reviewed -->`
- `# Round NN — <short title>`
- `**Status:** IN PROGRESS | DELIVERED | SUPERSEDED`
- Owner directive quoted verbatim
- Plan reference (`docs/ROUND-NN-MASTER-PLAN.md`)
- Per-MS section: workstreams landed, files touched, verification evidence
- Open items / questions for owner

## 8. The stamp-all script

When adding the `<!-- last-reviewed -->` contract to a repo that didn't have
it, run `node scripts/docs/stamp-all.mjs` to bulk-add the stamp to every
doc missing it. Re-run after large doc batches. The stamp uses the current
date + the round number from `docs/status.json`.

**The cohort-aging rule (R75):** the 3-round cap means a whole stamp
cohort fails `docs:check` at once — every round where `stampRound + 4 ≤
current` (R75 hit the round-71 cohort: 161 docs). `stamp-all.mjs` only
ADDS missing stamps (it never bumps existing ones), so a cohort failure
is fixed by bumping the aged stamps' date+round in place —
first-line-only diffs, verified with `git diff` before commit (the
R53/R54/R75 mass-stamp precedent). Run `pnpm docs:check` before every
release close-out.

## 9. What NOT to do

- Don't hand-edit generated docs (`docs/compliance/dependency-licenses.md`
  is generated by the license audit; `docs/agent/ORCHESTRATION-WORKLOG.md`
  is a snapshot of the live worklog — copy, don't hand-write).
- Don't link to local file:// URLs.
- Don't put secrets in docs (the denylist catches token patterns, but
  humans should not write them either).
- Don't skip the stamp "just this once" — CI fails on the next push.
