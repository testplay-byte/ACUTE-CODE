master switch OFF by default). While the switch is ON, after each completed

Entries are diagnostics for ACUTE-CODE's developers — they are never injected

### Suggested improvements
1. Fix or add a fallback for `browser_control(click)` when the embedded browser bridge returns `evalJob: unexpected start payload`; if native click fails, automatically retry with a JavaScript click via `eval` and report the fallback.
2. Make background-job metadata consistent: if a command redirects output to a file, `run_command` and `job_status` should report that file as the log/output path, not `nul`, and should surface the redirected file’s contents or creation state.
3. Ensure `browser_control(get_state)` reflects the actual current URL, including hash fragments, and returns the page title when available after `navigate`, `eval`, or `read_dom`.
4. Improve screenshot and click error diagnostics so minimized-window failures and native-input bridge failures are distinguished, rather than leaving the agent to infer a shared cause.
5. If `search_symbols` is intended to support substring queries, return matches for short identifiers like `ch` or include a hint that it requires exact/qualified symbol names.
