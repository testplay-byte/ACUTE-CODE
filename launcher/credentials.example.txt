==========================================================================
 ACUTE-CODE - credentials (template)
==========================================================================
 This file stays on YOUR PC. It is never uploaded, committed, or sent
 anywhere except directly to GitHub (to download the private repository)
 and, locally, into the app's secure key store. Rotate or clear any
 value at any time - nothing else needs to change.

 HOW TO USE - 3 steps, about a minute:

   1. Rename this file:  credentials.example.txt  ->  credentials.txt
      (in your file manager, or save a copy under the new name)

   2. Open it in any text editor (Notepad is fine) and paste your
      values on the lines in the PASTE ZONE below. Only the first
      two are REQUIRED - the three sub-agent keys are optional.

   3. Save the file, then double-click ACUTE.bat (Windows) or run
      'bash acute.sh' (Linux/macOS). The launcher does the rest.

--------------------------------------------------------------------------
 PASTE ZONE - replace each PASTE_YOURS_HERE with your real value
--------------------------------------------------------------------------

# REQUIRED - without these two the launcher stops and tells you exactly
# what is missing.

GITHUB_PAT=github_pat_PASTE_YOURS_HERE

OPENROUTER_KEY=sk-or-v1-PASTE_YOURS_HERE

# OPTIONAL - sub-agent pool keys (pool slots 2/3/4). Sub-agents use these
# first so your main key is not burdened by parallel child runs. Leave the
# placeholders to opt out - children then fall back to your main key.
# Filled keys appear automatically in the app under Settings > Sub-agents.

OPENROUTER_SUB1_KEY=sk-or-v1-PASTE_YOURS_HERE
OPENROUTER_SUB2_KEY=sk-or-v1-PASTE_YOURS_HERE
OPENROUTER_SUB3_KEY=sk-or-v1-PASTE_YOURS_HERE

--------------------------------------------------------------------------
 WHERE TO GET EACH VALUE
--------------------------------------------------------------------------

 GITHUB_PAT           A GitHub Personal Access Token with read access to
                      the private repository testplay-byte/ACUTE-CODE.
                      github.com -> Settings -> Developer settings ->
                      Fine-grained tokens.  Starts with: github_pat_

 OPENROUTER_KEY       Your main OpenRouter API key - used by the primary
                      agent and as the fallback for everything else.
                      openrouter.ai -> Keys.  Starts with: sk-or-v1-

 OPENROUTER_SUBn_KEY  Extra OpenRouter keys for the sub-agent pool (from
                      the same place as the main key). Optional.

--------------------------------------------------------------------------
 NOTES
--------------------------------------------------------------------------
 - Lines starting with # are comments and are ignored.
 - Blank lines are fine. Surrounding quotes ("..." or '...') are stripped.
 - Keep this file in the same folder as ACUTE.bat / acute.sh.
 - Empty or removed lines simply disable that key - nothing breaks.
 - The launcher never writes real keys into this file and no keys ship
   with it: every value comes from you, and only you.
